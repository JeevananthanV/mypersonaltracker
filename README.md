# 🚀 Jeeva's Life OS — All-in-One Personal Command Center

A modern, high-performance personal command center tailored for **Jeeva's 2026 Life Plan**: accelerating your transition to an **AI/ML Engineer**, managing your **₹34,000 monthly salary**, systematically eliminating your **₹2,50,000 personal loan**, keeping daily fitness habits (**57 kg / 160 cm**), and tracking active projects (**Ethiroli Portal, Jai Varahi Peedam, AI Portfolio**).

---

## 🌟 Live Features & Modules

### 1. 🏠 Command Center (Dashboard)
- **2026 Strategic Plan Banner**: Quick view of overarching priorities.
- **4 Key Metric Cards**: Real-time salary tracking, principal balance due, AI practice hours, and fitness consistency.
- **☀️ Today's Top 3 Priorities**: Interactive, prominent daily priority execution with checkmarks and confetti.
- **Daily Routine Checklist**: Morning and evening routine compliance.
- **Loan Reduction Milestone Preview**: Visual tracking of progress toward the ₹1 Lakh milestone.

### 2. 💰 Finance & Loan Freedom Center
- **Salary vs Expenses**: Tracks ₹34,000 monthly income against recurring rent, food, courses, and utilities.
- **Dedicated Loan Repayment Tracker**:
  - Opening Balance, Principal Paid, Interest Paid, Total Paid, Closing Balance.
  - Automatic deduction of principal balance.
- **Special ₹2,000 EMI Drop Milestone**:
  - Highlights your lender agreement: **Monthly EMI drops by ₹2,000 each time ₹1,00,000 of principal is cleared**.
- **Interactive Loan Feasibility Simulator**:
  - Slider to test monthly principal amounts (₹15k safe, ₹18k balanced, vs ₹31,250 aggressive 8-month payoff).
  - Calculates remaining monthly budget for living expenses to ensure you don't run short.
- **Interactive Visualizations**: Expense categories pie chart and monthly spending breakdown using Recharts.

### 3. 🧠 AI/ML Career Center
- **Career Blueprint**: Current module, skills to hone, flagship project, biggest blocker, and next practical milestone.
- **8-Module Core Curriculum**:
  - Python & Modern OOP
  - NumPy & Pandas
  - Math & Statistics
  - Data Visualization (Matplotlib / Seaborn)
  - Classic Machine Learning & Scikit-Learn
  - Deep Learning with PyTorch
  - MLOps & Model Deployment (FastAPI & Docker)
  - Portfolio Capstone Projects
- **Practice Hours Logger**: Track focused hours against targets with instant increment buttons (`+30m`, `+1h`, `+2h`).
- **Interactive Bar Chart**: Logged hours vs target curriculum hours.

### 4. ✅ Tasks & Daily Habits
- **Today's Top 3 Featured Section**: Eliminates overwhelm by keeping focus on only 3 core daily outcomes.
- **Task Manager Views**: Today, This Week, Completed, and Area filtering (Work, Learning, Finance, Personal).
- **Daily Execution Streaks**: Habit streaks with interactive check-in cards and streak counters.

### 5. 🏃‍♂️ Fitness & Wellness Tracker
- **Physical Profile**: Current Weight (57 kg), Height (160 cm), Normal BMI (22.3), and weekly consistency target (3 sessions/week).
- **Beginner-Friendly Weekly Schedule**:
  - Monday: Walking + Mobility (15–20 mins)
  - Wednesday: Light Skipping / Walking
  - Friday: Full-Body Gentle Movement
  - Other days: Rest & Hydration
- **Health & Safety Guidance**: Specifically designed to prevent previous muscle shaking by emphasizing joint mobility and bodyweight exercises over heavy resistance.
- **Daily Wellness Checklist**: 6 key daily habits (warm-up, exercise, stretching, 2.5L+ water, 7.5h+ sleep, logging).
- **Trends Charts**: Sleep, Water intake, and Body Weight stability tracking over time.

### 6. 💻 Software & AI Projects Center
- **Pre-Configured Real Projects**:
  - **Ethiroli Portal** (Client/Community Portal — In Progress)
  - **Jai Varahi Peedam Website** (Devotional Portal — Deployed / Maintenance)
  - **Production AI Sentiment & Topic Analyzer** (AI Portfolio Flagship — In Progress)
  - **Jeeva's Life OS** (Personal Command Center)
- **Project Tracking**: Progress sliders, tech stack tags, next action reminders, and links to GitHub code and live URLs.

### 7. 📅 Sunday Weekly Review
- **20-Minute Sunday Reflection Wizard**:
  1. What did I complete?
  2. What did I learn in AI/ML?
  3. How much did I spend & repay?
  4. What went wrong / biggest blocker?
  5. Next week's 3 non-negotiable priorities.
- **Trophy Wins Vault**: Celebrate weekly milestones with celebratory confetti.

### 8. 💡 Ideas & Prompt Vault
- Store AI system prompts, side project ideas, automation concepts, and mindset reminders.
- One-click copy, tag filtering, and pin-to-top functionality.

---

## 🛠 Tech Stack

- **Framework**: React 19 + Vite 8 + TypeScript
- **Styling**: Tailwind CSS v4 + Custom Glassmorphism + Responsive Layouts
- **Icons**: Lucide React
- **Data Visualizations**: Recharts
- **Celebrations**: Canvas Confetti
- **Storage**: Persistent LocalStorage with one-click JSON backup export & restore
